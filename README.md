# 📚 The Bookstore Intelligence Mission — Web Scraper

Business Data and Text Mining · Assignment 2
Scrapes the sandbox site <https://books.toscrape.com/> with **requests + BeautifulSoup**, builds a **Pandas** dataset, and answers business questions from it.

## What it does
1. Downloads each catalogue page (`catalogue/page-N.html`) in **one reusable loop** (no copy-paste).
2. Extracts **Title, Price, Rating, Availability** (+ **Product_URL**) from every `article.product_pod`.
3. Converts word ratings (`One`…`Five`) to numbers 1–5 and prices (`£51.77`) to floats.
4. Saves `competitor_books.csv`.
5. Answers the 7 intelligence questions, writes a data-backed recommendation, and solves the **CEO £100 challenge** exactly (0/1 knapsack via dynamic programming).
6. Bonus: URL column, rating counts, bar chart, and **Boss Level** – scrapes all pages by following the "next" button.

## HTML reconnaissance
| Data | HTML Tag / Class | Note |
|---|---|---|
| Title | `h3 > a[title]` | use the `title` attribute (link text is truncated) |
| Price | `p.price_color` | strip `£`, cast to float |
| Rating | `p.star-rating <Word>` | word is a CSS class → map to 1–5 |
| Availability | `p.instock.availability` | `get_text(strip=True)` |
| URL | `h3 > a[href]` | relative → `urljoin` |

## Run it
```bash
pip install -r requirements.txt
python scraper.py              # all pages (Boss level)
python scraper.py --pages 3    # first 3 pages
python scraper.py --pages 5    # Bonus 1
```
Or open `Bookstore_Scraper.ipynb` and run all cells.
